# Каталог скриншотов для менеджерских гайдов (UAT-3)

Кадры лежат в этой папке, рядом с каталогом. Заметки ниже — со сборки 27 ноября 2026 (Europe/Moscow). Пути `/workspace/uat/guide-shots/` относятся к той сборке.

В той сборке всё лежало в `/workspace/uat/guide-shots/`:

- `raw/` — чистые копии со стенда (оригиналы не менялись). Откуда какой файл: `raw/SOURCES.md`.
- `annotated/` — обрезка без панели чатов и вкладок, рамки, стрелки, выноски 1–2–3, русская легенда.
- `jobs/` — JSON для повторной сборки через `annotate.py`.
- `work/` — служебные сетки, в гайды не вставлять.

Собрано **26** сырых кадров, аннотировано **22**.
Архив для передачи: `/workspace/uat/guide-shots-annotated.zip` (`CATALOG.md` + папка `annotated/`).

Пересборка:

```bash
python3 /workspace/uat/guide-shots/annotate.py run-dir /workspace/uat/guide-shots/jobs/
```

На всех аннотированных кадрах левая колонка Telegram со списком чатов и контактов обрезана. В `shop-open.png` для этого задана явная обрезка с `x=380` (автоопределение оставляло 6 px белой кромки панели).
