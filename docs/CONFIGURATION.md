# Конфигурация

В `.env` лежат секреты и то, без чего процесс не поднять: токен бота, bootstrap-суперадмины, пути, доступы к Google и Nextcloud, адрес стека дашборда. Тексты, тарифы, вопросы анкеты, тумблеры модулей и имена вкладок таблицы менеджер меняет из бота — они живут в SQLite (`bot_settings` и соседние таблицы), не в файле на диске. Правка `.env` после первого запуска эти настройки не перезаписывает.

Кто разворачивает сервер, копирует [`.env.example`](../.env.example) в `.env`. Менеджер события после этого работает в `/admin`, без рестарта и без разработчика. Исключения, где рестарт всё-таки нужен, названы ниже.

Полный справочник по коду — [REFERENCE.md](REFERENCE.md). Как вести событие кнопками — [ADMIN_GUIDE.md](ADMIN_GUIDE.md). Домен и туннель — [DEPLOY-DOMAIN.md](DEPLOY-DOMAIN.md).

## Переменные окружения

Бот читает переменные классом `Settings` в [`config.py`](../config.py) (`pydantic-settings`, файл `.env`, кодировка UTF-8, `extra="ignore"`). Неизвестный ключ в `.env` старт бота не роняет.

Дашборд и Mini App читают **окружение процесса**, не файл `.env` напрямую: [`dashboard/config.py`](../dashboard/config.py) (`load_config`) и тонкая обёртка [`miniapp/config.py`](../miniapp/config.py) (`load_miniapp_config`). В Docker это одно и то же, потому что `env_file: .env` в [`docker-compose.yml`](../docker-compose.yml) подставляет файл в окружение контейнера. Локальный `python main.py` видит `.env` через pydantic; локальный `uvicorn` дашборда или Mini App увидит `DASHBOARD_*` только если переменные уже есть в окружении процесса.

Секреты в таблицу не подставляются. Примеры ниже — форматы из `.env.example` и дефолты из кода, не рабочие значения.

## Формат конфигурационных файлов

Отдельного `config.yaml` / `config.toml` нет. Три места, куда смотреть.

### `.env`

Плоский `КЛЮЧ=значение`, комментарии — строки с `#`. Файл в корне репозитория, рядом с `main.py`. Шаблон с пояснениями — [`.env.example`](../.env.example). В git `.env` не входит.

Списки:

- `ADMIN_IDS` у бота — JSON-массив целых чисел.
- `PROXY_URL_BACKUP` — несколько каналов через запятую.
- `EVENT_CITIES` — записи `код|подпись|база_вкладки` через `;`.
- `DASHBOARD_EVENTS` — `код=абсолютный_или_контейнерный_путь` через `;` или перевод строки.
- `DASHBOARD_SUPERADMIN_EMAILS` — адреса через запятую, `;` или перевод строки.

Кавычки вокруг значения `GOOGLE_SHEET_TAB` и `GOOGLE_SHEET_ID` код срезает сам. Секреты (`BOT_TOKEN`, пароли прокси, app-password, секрет Яндекса, `DASHBOARD_SESSION_SECRET`, `TUNNEL_TOKEN`) в репозиторий, в логи настроек и в этот файл не пишутся.

`tunnel/.env` — один ключ `TUNNEL_TOKEN=`. Compose туннеля читает его через свой `env_file`, из каталога `tunnel/`.

### `google_credentials.json`

JSON-ключ сервисного аккаунта Google (скачивается в Cloud Console, кладётся по пути `GOOGLE_CREDENTIALS_FILE`). Это не пример, который можно сочинить: в файле приватный ключ аккаунта. Таблицу расшаривают на `client_email` из этого JSON с правом редактора. Без файла и без ID таблицы бот работает на SQLite. Пошаговая настройка API — в [README.md](../README.md), раздел «Конфигурация».

### Настройки менеджера — база, не файл

Таблица `bot_settings` (`key TEXT PRIMARY KEY`, `value TEXT NOT NULL`) создаётся в [`database/db.py`](../database/db.py). Реестр ключей, типов, групп, подписей и дефолтов — словарь `SETTINGS_SCHEMA` в [`domain/settings/schema.py`](../domain/settings/schema.py). Чтение с типом и дефолтом — `get_setting_typed`. Нет строки в базе — берётся `default` записи реестра, а не значение из `.env`.

Типы: `text`, `enum`, `int`, `toggle`, `list`, `multi`, `date` (`ДД.ММ.ГГГГ ЧЧ:ММ`), `date_only` (`ДД.ММ.ГГГГ`), `photo`, `file`. Мусор в `int` и дате сбрасывается в дефолт. У `enum` пустая строка тоже означает дефолт.

Где править: `/admin` → «⚙️ Настройки форума». И бот, и веб-настройки Mini App пишут в одну таблицу `bot_settings`, но списки разделов не совпадают. Ниже — `SECTION_GROUPS` ([domain/settings/ops.py](../domain/settings/ops.py)), не экраны бота (`SECTIONS` в [handlers/settings/admin_sections.py](../handlers/settings/admin_sections.py)): в боте есть «📢 Общение», у оплаты и амбассадоров нет строки группы настроек, группы «🔧 Управление» другие:

| Раздел | Группы |
|---|---|
| 🎪 Событие | событие и медиа, кнопки меню, подписи кнопок |
| 📝 Анкета | вопросы, тексты вопросов, регистрация, вечеринка, согласия |
| 📋 Заявки | заявки |
| 💳 Оплата | оплата |
| 🎮 Геймификация | геймификация |
| 🤝 Амбассадоры | амбассадоры |
| 📊 Данные | вкладки таблицы, дашборд |
| 🔧 Управление | приложение, чат делегатов, ВКонтакте, система |

Поиск по подписи — «🔎 Найти настройку». Коды ключей человеку не показываются.

Городское переопределение, если у ключа в реестре `per_city`, хранится отдельно: `{ключ}__city__{код_города}`. Нет городской строки — действует общее значение.

Что в базе, но не в `bot_settings`:

- Города — таблица `cities` (экран «🏙 Города мероприятия»): подпись, база вкладки, вкл/выкл, порядок. Код города менеджер не вводит.
- Какая Google-таблица — ключ `google_sheet_id`, экран «📊 Данные → 🔗 Какая таблица», только суперадмин из `ADMIN_IDS`. Пусто — остаётся `GOOGLE_SHEET_ID` из `.env`. Сбой чтения базы не откатывается на `.env`: запись пропускается, чтобы не уехать в чужую таблицу.
- Ключи Яндекса и токены менеджера — `external_form_secrets` и `external_form_connections`. В `bot_settings` их нет: `set_setting` пишет значение в лог, секреты туда не кладут.
- Ключ сообщества ВК — всё же `bot_settings.vk_community_token`, но запись реестра помечена `sensitive`: в лог и на экран уходит «установлен», не сам ключ. Задаётся в группе «💬 ВКонтакте», не через `.env`.

Имя основной вкладки: сначала `bot_settings.main_sheet_tab`, потом `GOOGLE_SHEET_TAB`, потом старый pin названия. Ничего из этого нет — запись в лист отказывает и говорит открыть «📄 Вкладки таблицы».

Отложенные задачи планировщика лежат отдельно: `data/jobs.sqlite` (URL зашит в [`services/scheduler.py`](../services/scheduler.py) как `sqlite:///data/jobs.sqlite`). Это не `DB_PATH`. Смена пути базы форума файл джоб не переносит.

Справочники `data/lookup/cities_ru.json` и `data/lookup/universities_ru.json` — данные поиска в анкете, не настройки события.

## Обязательные и необязательные настройки

Процесс не стартует только без того, без чего нельзя подписать сессию или вызвать Bot API. Всё остальное имеет дефолт или молча выключает кусок функции.

**Бот** (`python main.py`, контейнер `bot`). При импорте `config.Settings()` pydantic требует два поля. Нет их в `.env` и в окружении — процесс падает до поллинга, с ошибкой валидации, не с самодельной фразой:

- `BOT_TOKEN`
- `ADMIN_IDS`

Пустые Google, Nextcloud, прокси, Яндекс и `DASHBOARD_PUBLIC_URL` бот поднимают. Нет `GOOGLE_SHEET_ID` и нет таблицы в боте — синхронизация с листом не идёт. Nextcloud считается включённым, только если заданы все три: `NEXTCLOUD_WEBDAV_URL`, `NEXTCLOUD_PUBLIC_URL`, `NEXTCLOUD_FOLDER_SHARE_TOKEN` (`is_configured` в [`services/registration/nextcloud.py`](../services/registration/nextcloud.py)). Нет любого — резюме остаётся `file_id` в Telegram, регистрация не ломается. Ошибка PUT тоже не ломает анкету.

**Mini App** (тот же образ, команда `uvicorn miniapp.main:app`). Нужны и поля бота (`BOT_TOKEN`, `ADMIN_IDS` — импорт `config`), и `DASHBOARD_SESSION_SECRET`. Нет секрета сессии — `RuntimeError`: «DASHBOARD_SESSION_SECRET не задан в .env этого стека…».

**Дашборд** (свой образ, `dashboard/Dockerfile`, `config.py` бота внутрь не копируется). Обязателен только `DASHBOARD_SESSION_SECRET`, с тем же текстом ошибки. Без `DASHBOARD_BOT_USERNAME` и `BOT_TOKEN` виджет входа не собрать, процесс при этом стартует. Без `DASHBOARD_EVENTS` это дашборд одного события.

**Туннель.** Без `TUNNEL_TOKEN` контейнер `cloudflared` из `tunnel/docker-compose.yml` не подключится к Cloudflare. <!-- VERIFY: имя туннеля и публичные hostname задаются в панели Cloudflare, не в репозитории -->

Настройки реестра обязательными для старта не являются. Пока менеджер ничего не сохранил, фичи стоят на дефолтах `SETTINGS_SCHEMA` (большинство модулей выключено, например меню «день форума» и ответы ВКонтакте — `off`).

Прокси-тайминги (`proxy_recheck_seconds`, `proxy_connect_timeout`, `proxy_switch_dwell_seconds`) читаются один раз при создании сессии. Смена в «🔧 Система» видна после перезапуска бота. Остальные ключи реестра, у которых подсказка не просит рестарт, подхватываются при следующем чтении. Интервалы джоб планировщика перепланируются сразу при записи.

## Значения по умолчанию

Дефолты `.env` заданы в коде, не только в комментариях шаблона. Если переменную убрать, бот получит значение из колонки «По умолчанию» выше.

Отдельно, потому что их легко перепутать с настройками менеджера:

| Что | Дефолт | Где задан |
|---|---|---|
| Файл базы | `data/forum.db` | `DB_PATH` и `DASHBOARD_DB_PATH` |
| Файл джоб | `data/jobs.sqlite` | литерал в `services/scheduler.py`, не переменная |
| Лог | `logs/bot.log`, уровень `INFO`, ротация 10 МБ × 5 | `main.py`, `_configure_logging` |
| Heartbeat | temp-файл, интервал записи 30 с, `--check` считает файл протухшим после 120 с | `services/heartbeat.py` |
| Доверенные прокси дашборда | `172.31.0.0/16` | `DEFAULT_TRUSTED_PROXIES` в `dashboard/config.py` |
| Города при пустой таблице | три города из дефолта `EVENT_CITIES`, первым по порядку — код `EVENT_CITY_DEFAULT` | `seed_cities_if_empty` |
| Потолок резюме в облако | 20 МБ | `RESUME_MAX_MB` |
| Папка резюме | `resumes` | `NEXTCLOUD_FOLDER` |
| Проверка TLS Nextcloud | включена | `NEXTCLOUD_VERIFY_TLS` |
| Возврат на основной прокси | 600 с, если менеджер не сохранял ключ | реестр `proxy_recheck_seconds`; `.env` пишет строку только когда отличается от 600 и строки ещё нет |
| Таймаут соединения с прокси | 5 с, то же правило seed | реестр `proxy_connect_timeout` |
| Пауза между переключениями прокси | 30 с | реестр `proxy_switch_dwell_seconds`, из `.env` не сеется |
| Каталог моделей перевода | `data/argos` | `ARGOS_PACKAGES_DIR`, если переменная не задана |
| Драйвер перевода | `embedded` | реестр `delegate_lang_driver` |
| Адрес HTTP-драйвера | `http://libretranslate:5000` | реестр `delegate_lang_http_url` |

Seed прокси и вкладки идемпотентный. Уже сохранённое менеджером значение повторный старт не затирает. `GOOGLE_SHEET_TAB` пустой — в базу ничего не пишется. `PROXY_*` равный дефолту реестра — тоже ничего не пишется, чтобы не плодить лишнюю строку.

Дефолты текстов, сумм, тумблеров и списков — поле `default` каждой записи `SETTINGS_SCHEMA`, не этот документ. Их сотни, править список здесь значило бы разойтись с кодом. Смотреть подпись и заводское значение — на экране настройки: подсказка показывает пример формата. Сброс многих текстов — отправить `-`.

Заводской текст «бесплатное участие» (`default_free` у части записей) подставляется только если своей строки в `bot_settings` нет и оплата для этого города выключена. Сохранённое значение, даже пустое, сильнее обоих наборов.

## Разные окружения

Файлов `.env.development`, `.env.production` и `.env.test` в репозитории нет. Окружение — это отдельный каталог со своим `.env`, своей базой в `./data` и своим `docker compose`. Один и тот же код, разные секреты и разные `bot_settings`. `DASHBOARD_SESSION_SECRET` между стеками не переиспользуют: иначе cookie одного события подошла бы к другому.

В compose у `bot`, `yl26-dashboard` и `miniapp` стоит `env_file: [".env"]`. Подмена «prod/stage» — другой каталог на сервере, не другой профиль pydantic. Перед `docker compose` имеет значение текущий каталог: у каждого события свой compose. <!-- VERIFY: живые пути каталогов на сервере в этом файле не фиксируются; схема выкладки — docs/DEPLOY-DOMAIN.md -->

Что отличается по роли процесса, а не по имени окружения:

- Контейнер бота пишет `data/forum.db` и `data/jobs.sqlite`, читает `google_credentials.json`, шлёт heartbeat.
- Дашборд читает ту же базу (том `./data:/app/data` без `:ro`: рядом нужен WAL `-shm`). В подключении дашборд сам открывает SQLite только на чтение.
- Mini App — второй писатель в ту же базу (сдачи и правки менеджера). Ему нужен и ключ Google: он дописывает служебные вкладки.
- Супердашборд — тот же код дашборда плюс непустой `DASHBOARD_EVENTS`, список e-mail и пара `DASHBOARD_ACCESS_TEAM_DOMAIN` / `DASHBOARD_ACCESS_AUD`. Обычному стеку мероприятия эти четыре переменные не задают.
- Локальная отладка сводного экрана без Cloudflare: `DASHBOARD_ACCESS_DEV_BYPASS=1`. В проде переменную не задают.
- Перевод через LibreTranslate: профиль compose `i18n` и служебный ключ `delegate_lang_driver=http`. По умолчанию профиль не поднимается и драйвер — встроенный.
- `GIT_SHA` при сборке помечает образ коммитом. Пусто — метка `unknown`.

Рестарт бота не сбрасывает анкеты, которые делегат заполняет в этот момент: FSM лежит в SQLite (`SqliteStorage` в [database/fsm_storage.py](../database/fsm_storage.py), `Dispatcher(storage=SqliteStorage())` в [main.py](../main.py)). Настройки в `bot_settings` рестарт не сбрасывает. Перед рестартом на живом событии смотрят свежие черновики: `tools/quiet_minute.py`.
