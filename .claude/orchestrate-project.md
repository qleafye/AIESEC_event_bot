# Проектные правила для скилла orchestrate — AIESEC Event Bot

## Пулы: признаки этого репо

- **сложная** (старт opus): города и `per_city`-настройки, шапка города в админке; права
  (`handlers/access/admin_caps.py`, роли); миграции `database/db.py` (`_ensure_column`,
  `PRAGMA user_version`); `services/scheduler.py` и джобы APScheduler; запись в Google-таблицы
  (сдвиг колонок ломает строки); всё, что меняет данные боевой базы.
- **обычная** (старт sonnet): экран админки или делегата по образцу соседнего; новая настройка
  реестра с чтением в коде; хендлер в одном модуле.
- **механика** (старт haiku, пачкой): ключ `domain/settings/schema.py` по образцу соседнего,
  английский перевод ключей (`services/i18n/`), подписи кнопок, данные справочников
  (`data/lookup/`), тест по образцу соседнего.

## Правила, которые исполнитель получает в постановке

- Админка — кнопками; менеджеру не показываем кодовые значения; ошибка объясняет, что сделать.
- Тексты для людей по-русски; «АЙСЕК» / «Юлид» кириллицей (латиница — только хэштеги, ники, код).
- Коммит по-русски `тип(скоуп): тема`, скоуп — модуль (`admin`, `registration`, `payment`,
  `game`, `db`, `sheets`, `scheduler`, `config`, `tests`, `miniapp`, `dashboard`), без номеров
  планов и ID ревью, без строки `Claude-Session`.
- Сменил `callback_data` — прогнать `tests/test_roles_phase8*.py` и `tests/test_admin_caps*.py`,
  префикс добавить в `admin_caps.py`. Сменил текст — `rg` старой строки по `tests/`.

## Команды проверки

- Точечно: `python -m pytest tests -q -n 8 -k "<ключевые слова>"` (облако: `-n 4`).
- Полный: `python -m pytest tests -q -n 8` (локально ~20 мин; перед ним очистить
  `%TEMP%\pytest-of-alexe`; облако: `-n 4`).
