| scheduled_broadcasts payload → user sends | stored text/photo dispatched to a target set |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-3-02 | Tampering | jobstore pickle in data/jobs.sqlite | accept | Local file only, not network-exposed; args restricted to int broadcast_id (no callables/closures) — RESEARCH.md:513 |

| T-3-14 | Denial of Service | scheduled send loop flooding under 429 | mitigate | 429-safe loop copied from _welcome_flipped (sleep retry_after+1, single retry) + 0.05s pacing |
</threat_model>
