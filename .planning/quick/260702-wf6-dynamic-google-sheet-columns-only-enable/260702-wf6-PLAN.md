# Quick 260702-wf6 — Dynamic Google Sheet columns + rename duplicate labels

## Goal
Google Sheet always wrote all 44 columns (disabled questions → "-"), so a forum event with
~11 questions produced a 44-wide sheet. Make sheet width follow the enabled questions. Also
disambiguate the near-duplicate expectation/comment question labels in admin.

## Approach (variant A, workflow-safe)
Columns are gated by their `reg_q_*` setting; system columns (ID/username/date/ФИО/details)
always present. Headers + rows derive from a single `SHEET_COLUMNS` spec so they never drift
apart within a run. Event type is set before delegates register (user-confirmed), and the
physical header row is created once by `ensure_sheet_header`, so mid-event toggle changes do
not reshuffle existing rows.

## Tasks
1. `handlers/registration.py`: `SHEET_COLUMNS` spec (header, gate, value_fn). Derive
   `SHEET_HEADERS` (full, kept for tests) + `_build_sheet_row` (full). Add
   `active_sheet_headers()` / `active_sheet_row()` / `_sheet_value_map()`. Rename labels:
   Ожидания (общие) / Ожидания: организация / Ожидания: контент / Доп. комментарии.
2. Wire live paths to the active projection: `registration.py` finalize append, `main.py`
   startup header, `admin.py` sync (header once, rows aligned to it).
3. Tests: active headers shrink with the forum preset; full width when all on.

## Verify
- `python -m pytest tests/ -q -p no:asyncio` green.
- Manual: forum preset → 16 cols, conf → 20, all-on → 44.
