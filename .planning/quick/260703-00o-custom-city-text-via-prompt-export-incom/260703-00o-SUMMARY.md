# Quick 260703-00o — Summary

Team asks (Юлия): custom city text + where to see incomplete registrations.

## Q1 — «Другое» → free-text entry (`handlers/registration.py`)
Tapping «Другое» on any option keyboard stored the literal word «Другое». Now «Другое» re-prompts
for the value and stays in the same state, so the next typed message is stored as the real answer.
Applied to: city, source, local_committee, position, university, and the generic select_input step
(study_field etc.). Typing a value directly already worked; this fixes the button path.

## Q2 — export incomplete registrations (`database/db.py`, `services/sheets.py`, `handlers/admin.py`)
Dropouts (hit /start, never finished) lived only in the `reg_started` table — no sheet view.
- `db.get_incomplete_rows()` → (telegram_id, username, started_at). Partial answers aren't
  persisted (in-memory FSM), so only identity + start time exist.
- `sheets.sync_named_worksheet(title, headers, rows)` → get-or-create a tab, clear, write header+rows
  (full refresh). Fail-soft, returns -1 on error.
- Admin button «📝 Незавершённые → таблица» (`admin_export_incomplete`) writes them to a dedicated
  «Незавершённые» tab and reports the count.
