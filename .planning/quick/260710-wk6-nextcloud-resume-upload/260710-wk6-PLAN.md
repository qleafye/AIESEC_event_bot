<objective>
Add self-hosted Nextcloud integration: when a delegate finishes registration with a FILE
resume (`resume_file_id` set), download the file from Telegram, upload it to Nextcloud via
WebDAV, create a password-protected public share link via the OCS Share API, and persist that
link in a new `resume_url` DB column and a new "Резюме (ссылка)" Google Sheet column.
Text-only resumes are untouched. The whole path is fail-soft — Nextcloud being down, slow, or
unconfigured must never block or break registration.

Purpose: give managers a clickable resume link in the sheet instead of only an in-bot file_id.
Output: `services/nextcloud.py`, new config fields, `resume_url` column + label, finalize
wiring, new sheet column, and tests.
</objective>

<task type="auto">
  <name>Task 2: services/nextcloud.py — fail-soft upload_resume</name>
  <files>services/nextcloud.py</files>
  <action>
Create `services/nextcloud.py` with `import asyncio, logging, uuid, re, aiohttp`, `logger = logging.getLogger(__name__)`,
and `from config import config`.

Implement `async def upload_resume(bot, file_id: str, filename: str) -> str | None`. Wrap the
ENTIRE body in try/except so nothing ever raises to the caller — on any exception log at error
level and return None.

Steps:
1. If `not config.NEXTCLOUD_BASE_URL or not config.NEXTCLOUD_WEBDAV_URL`: log debug "nextcloud disabled" and return None (feature off).
2. Download bytes: `buf = await bot.download(file_id)`; `buf.seek(0)`; `content = buf.read()`.
3. Build a collision-safe remote name: sanitize `filename` (strip path, keep `[\w.\-]`, fallback
   "resume") and prefix with a short token, e.g. `f"{uuid.uuid4().hex[:8]}_{safe}"`. Ensure a
   sensible extension is preserved from the original filename.
4. Determine TLS: `ssl_arg = None if config.NEXTCLOUD_VERIFY_TLS else False` (aiohttp `ssl=False`
   disables verification for self-signed certs).
5. Build basic auth: `aiohttp.BasicAuth(config.NEXTCLOUD_USER, config.NEXTCLOUD_APP_PASS.get_secret_value() if config.NEXTCLOUD_APP_PASS else "")`.
6. In one `async with aiohttp.ClientSession(auth=auth) as session:` with a total timeout
   (`aiohttp.ClientTimeout(total=15)`):
   - PUT the bytes to `f"{config.NEXTCLOUD_WEBDAV_URL.rstrip('/')}/{config.NEXTCLOUD_FOLDER}/{unique_name}"`
     with `data=content, ssl=ssl_arg`. Accept 200/201/204 as success; otherwise log status+body and return None.
   - POST the share: `f"{config.NEXTCLOUD_BASE_URL.rstrip('/')}/ocs/v2.php/apps/files_sharing/api/v1/shares?format=json"`
     with headers `{"OCS-APIRequest": "true"}`, and form data
     `{"path": f"/{config.NEXTCLOUD_FOLDER}/{unique_name}", "shareType": "3", "permissions": "1"}`
     plus `"password": config.NEXTCLOUD_SHARE_PASSWORD.get_secret_value()` only when set, `ssl=ssl_arg`.
   - Parse JSON; extract the link from `ocs.data.url` (OCS v2 JSON shape:
     `resp["ocs"]["data"]["url"]`). If missing, log and return None. Never log the password.
7. Return the parsed URL string.

NOTE: aiogram 3.24.0 `await bot.download(file_id)` returns a BytesIO; if unavailable use
`f = await bot.get_file(file_id); buf = await bot.download_file(f.file_path)`. Pick whichever the
installed aiogram exposes; keep it inside the try/except.
  </action>
