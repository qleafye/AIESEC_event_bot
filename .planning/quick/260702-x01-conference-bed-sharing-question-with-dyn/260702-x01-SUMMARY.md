# Quick 260702-x01 — Summary

Added a conference bed-sharing question with a dynamic follow-up.

## Flow
1. **bed_sharing** (Да/Нет): «На площадке много двуспальных кроватей. Готов(а) спать с кем-то
   на одной кровати?»
2. **bed_partner** (free text, conditional): asked only when bed_sharing starts with «Да» —
   «С кем хотел(а) бы делить кровать? Напиши имя или «без разницы».» On «Нет» → next question.

## Changes
- `handlers/states.py`: `Registration.bed_sharing`, `Registration.bed_partner`.
- `handlers/registration.py`:
  - `REG_FLOW`: `bed_sharing` + `bed_partner` inserted after `housing` (conf logistics block).
  - `REG_DEFAULTS` off; `REG_LABELS` (🛏 Общая кровать / 🛏 Сосед по кровати).
  - `REG_CATEGORIES` «🎤 Конфа» bucket; `REG_PRESETS['conf']` enables both.
  - `_get_enabled_steps`: skip `bed_partner` unless `bed_sharing` starts with «Да» (dynamic branch).
  - `_ask_step` branches (Да/Нет reply kb; partner text + skip kb); handlers `process_bed_sharing`
    (`_store_choice`), `process_bed_partner` (`_store_text`).
  - `SHEET_COLUMNS`: «Общая кровать» + «Сосед по кровати» inserted after «Проживание» (not at end,
    so SHEET_HEADERS[-1] stays «Дата план. оплаты»).
  - `_build_summary`: two bed lines.
- `database/db.py`: `_ensure_column` bed_sharing/bed_partner; `add_user` INSERT columns +
  placeholders + ON CONFLICT SET + params; `CSV_HEADER_LABELS` RU labels.
