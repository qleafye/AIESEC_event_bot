# Quick 260702-w50 — Summary

Event-type presets (Forum / Conference) + categorized question toggles in admin.

## What changed

### `handlers/registration.py` (data only — no behavior change)
- `REG_PRESETS` — `forum` and `conf`, each listing the `reg_q_*` keys to turn ON plus a
  `payment_enabled` value. Applying is an explicit admin action; nothing runs on startup,
  `REG_DEFAULTS` and the flow engine are untouched, so live bots are unaffected until a tap.
- `REG_CATEGORIES` — disjoint display buckets (👥 Общие / 🏛 Форум / 🎤 Конфа / ➕ Экстра)
  covering all 40 `REG_FLOW` keys once. Cosmetic grouping only.

### `handlers/admin.py`
- `🎛 Тип события (пресет)` button in Settings → `admin_event_preset` menu → per-preset
  `preset_apply:<key>` confirmation card (lists what turns on, payment on/off, overwrite
  warning) → `preset_confirm:<key>` runs `_apply_event_preset` (sets every REG_DEFAULTS key
  on/off deterministically + payment_enabled), then re-renders the question view.
- Question toggle view (`render_questions_text` / `build_questions_keyboard`) now grouped by
  `REG_CATEGORIES` with section-header rows (`reg_q_noop` non-actionable callback). Any key
  not in a bucket falls into a trailing «📦 Прочие» group so nothing is hidden.

## Safety
Additive. Presets write the same settings the per-question toggles already write. No preset
is applied automatically. Confirmed: `REG_CATEGORIES` covers every `REG_FLOW` key exactly
once; preset `on` lists reference only real `REG_DEFAULTS`/`REG_LABELS` keys.
