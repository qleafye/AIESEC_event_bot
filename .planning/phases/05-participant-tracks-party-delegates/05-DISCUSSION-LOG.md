## Pre-discussion decisions (captured before /gsd-discuss-phase)

These were settled in the conversation that led to creating Phase 5 and were not re-asked.

| Question | Options | Chosen |
|---|---|---|
| Как моделировать ночёвку? | Отдельный трек (3 варианта) / Трек + отдельный вопрос | Отдельный трек: `full` / `party_overnight` / `party_noovernight` |
| Как выдавать party-ссылку? | Гибрид ссылка+вопрос / Только вопрос / Только спец-ссылка | Только спец-ссылка, с записью трека в БД как страховкой; вопрос-развилка за тумблером default off |

| Оплата для party | Тарифы по трекам / Не трогаем / Бесплатно | Тарифы по трекам |

**Note on the entry decision:** the assistant initially recommended a hybrid (deep link *plus* an always-visible fork question). The user pushed back — an ordinary delegate seeing «ты пати-делегат?» is a real UX cost for a weak benefit. The assistant agreed the hybrid was over-engineered and replaced the insurance mechanism with DB persistence of the track, which solves the same problem without the extra screen.
