Deliver VERIF-01/02: a pre-selection gate at `/start`. ## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| /start user input (username) → allowlist check | untrusted username compared to the cached set |
| Google Sheet tab → RAM allowlist cache | manager-controlled source of truth, read-only |
| admin callback/command → bot | refresh trigger bypasses message-level is_admin |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-3-09 | Spoofing | allowlist bypass via username case/whitespace/leading-@ | mitigate | `_normalize` (strip/lstrip @/lower) on BOTH sheet values and the incoming username before set membership (D-10, unit-tested) |
| T-3-10 | Elevation of Privilege | /refresh_allowlist command + button | mitigate | `is_admin` filter on the command + per-callback `config.ADMIN_IDS` re-check (precedent admin.py:872) |
| T-3-11 | Spoofing (gate bypass) | empty/stale allowlist when preselect_enabled=on (tab missing/refresh failed) | accept | Fail-open + loud admin warning on refresh when size==0; default OFF makes turning gating ON a deliberate act (Open Q2) — documented for the admin |
| T-3-12 | Information Disclosure | echoing username / sheet text / link back in HTML | mitigate | `html.escape` any user/sheet value rendered in gate replies (V5) |
| T-3-13 | Denial of Service | gspread call on every /start (quota/latency) | mitigate | RAM `set` cache; `/start` never calls gspread; refresh only at startup/interval/admin trigger (D-11) |
</threat_model>
