|-----------|----------|-----------|-------------|-----------------|
| T-0204-01 | DoS (busy-loop / tiny interval) | pending_reminder_loop | mitigate | `_reminder_interval` floors invalid/<=0 values to 1800; the loop always sleeps `interval` each pass, so a malformed setting cannot spin the CPU. Admins can set a small interval deliberately (documented in /settings_guide) but not accidentally via bad input. |
| T-0204-02 | Availability | reminder loop | mitigate | Each iteration is wrapped in try/except (log + continue) and each admin send is individually try/excepted, so a DB error or blocked admin never kills the loop. |
| T-0204-03 | Info disclosure | reminder message | accept | Message contains only an aggregate count, sent only to config.ADMIN_IDS. No applicant PII. |
