## Быстрый старт

### 1. Клонировать репозиторий

```bash
git clone <url>
cd AIESEC
```

### 2. Создать виртуальное окружение

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# Linux / macOS
source .venv/bin/activate
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Настроить переменные окружения

Скопировать `.env.example` в `.env` и заполнить:

```env
# Токен бота от @BotFather
BOT_TOKEN=123456789:ABCDefGHIjkLLmnoPQRstuVWxyz

# Telegram ID админов (через запятую в формате JSON-списка)
ADMIN_IDS=[12345678, 87654321]

# Прокси (опционально, если Telegram API заблокирован)
# PROXY_URL=socks5://user:pass@host:port

# Google Sheets (см. раздел ниже)
GOOGLE_SHEET_ID=your_google_sheet_id_here
GOOGLE_CREDENTIALS_FILE=google_credentials.json
```

**Как узнать свой Telegram ID:** отправьте `/start` боту [@userinfobot](https://t.me/userinfobot).

### 5. Запустить бота

```bash
python main.py
```

Бот автоматически создаст базу данных `data/forum.db` при первом запуске.

### Запуск через Docker (альтернативный способ)

```bash
docker-compose up -d --build
```

Docker Compose автоматически подхватит `.env`, примонтирует `data/` (БД), `resources/` (фото) и `google_credentials.json`. Логи: `docker-compose logs -f bot`.

## Настройка Google Таблицы

Бот дублирует каждую регистрацию в Google Sheets. Это опционально — если `GOOGLE_SHEET_ID` не указан, бот работает только с локальной БД.

При ошибке записи бот автоматически повторяет попытку до 3 раз (с задержками 5 / 15 / 30 сек).

### 1. Создать сервисный аккаунт Google

1. Откройте [Google Cloud Console](https://console.cloud.google.com/)
2. Создайте проект (или выберите существующий)
3. Перейдите в **APIs & Services → Library**
4. Найдите и включите **Google Sheets API** и **Google Drive API**
5. Перейдите в **APIs & Services → Credentials**
6. Нажмите **Create Credentials → Service Account**
7. Дайте имя (например `skillup-bot`) и нажмите **Done**
8. Откройте созданный сервисный аккаунт → вкладка **Keys**
9. **Add Key → Create new key → JSON** → скачается файл

### 2. Положить ключ в проект

Переименуйте скачанный JSON-файл в `google_credentials.json` и положите его в корень проекта (рядом с `main.py`).

> **Важно:** Этот файл содержит секретный ключ. Не коммитьте его в git. Он должен быть в `.gitignore`.

### 3. Создать Google Таблицу

1. Создайте новую таблицу в [Google Sheets](https://sheets.google.com)
2. Скопируйте ID таблицы из URL:
   ```
   https://docs.google.com/spreadsheets/d/ЭТОТ_ID_НУЖЕН/edit
   ```
3. Вставьте ID в `.env` как `GOOGLE_SHEET_ID`

### 4. Дать доступ сервисному аккаунту

1. Откройте файл `google_credentials.json` и найдите поле `client_email` — это email сервисного аккаунта (вида `name@project.iam.gserviceaccount.com`)
2. В Google Таблице нажмите **Поделиться** (Share)
3. Вставьте этот email и дайте роль **Редактор** (Editor)

### 5. Формат таблицы

Бот записывает данные в первый лист (`Sheet1`). Колонки заполняются автоматически. Рекомендуемые заголовки:

| # | Колонка | Описание |
|---|---------|----------|
| 1 | Telegram ID | ID пользователя |
| 2 | Username | @username |
| 3 | Дата регистрации | YYYY-MM-DD HH:MM:SS |
| 4 | ФИО | Имя и фамилия |
| 5 | Возраст | Число |
| 6 | Email | Электронная почта |
| 7 | Источник | Откуда пришёл |
| 8 | Детали | Referrer ID и т.д. |
| 9 | Телефон | Номер телефона |
| 10 | Город | Город участника |
| 11 | Лок. комитет | Локальный комитет AIESEC |
| 12 | Позиция | AIESECer / Alumni / Friend |
| 13 | Статус обучения | Учится / завершил / нет |
| 14 | ВУЗ | Название |
| 15 | Курс | 1–5+ / Магистратура |
| 16 | Специальность | Текст |
| 17 | Работает | Yes/No |
| 18 | Сфера работы | Текст |
| 19 | Навыки | Чего не хватает |
| 20 | Ожидания | От форума |
| 21 | Ожидания AR | От годового отчёта |
| 22 | Неформальный день | Да / Нет / Онлайн |
| 23 | Формат | Offline / Online |
| 24 | Комментарии | Свободный текст |

Заполняются только включённые в настройках вопросы. Остальные — прочерки.

## Гайд для админов

Админы — пользователи, чьи Telegram ID указаны в `ADMIN_IDS` в `.env`. Все админские команды и кнопки доступны только им.

### Админ-панель

Отправьте `/admin` в чат с ботом. Появится панель с кнопками:

| Кнопка | Что делает |
|--------|------------|
| 📊 Статистика регистраций | Общее число зарегистрированных + топ-3 ВУЗа |
| 🗓 Регистрации по месяцам | Разбивка по месяцам |
| 📈 Источники | Откуда приходят пользователи (метки, рефералки и т.д.) |
| 📄 Экспорт CSV | Скачать базу пользователей как CSV-файл |
| 📢 Рассылка | Массовая отправка сообщения |
| 🔄 Синхронизация таблицы | Догнать Google Sheets по БД (см. ниже) |
| ⚙️ Настройки форума | Управление контентом без перезапуска бота |

Также доступны текстовые команды: `/stats`, `/stats_monthly`, `/export`, `/broadcast`, `/find`, `/create_link`.

### Настройки форума

Через **⚙️ Настройки форума** можно менять прямо в Telegram:

**Форма регистрации:**

Кнопка «📝 Регистрация» переключает режим:
- **⚡ Краткая** (по умолчанию) — только имя
- **📋 Полная** — имя + все включённые вопросы (настраиваются в конструкторе)

Переключение мгновенное — новые пользователи сразу получат выбранную форму.

**Текстовые поля:**
- 🗓 Дата форума
- ⌚ Время проведения
- 📍 Название площадки
- 📫 Адрес площадки
- 👤 Контактное лицо (@username)
- 🔵 Ссылка на VK
- 🔹 Ссылка на Telegram-канал
- 💬 Приветственное сообщение (при `/start`, поддерживает HTML-разметку)
- 📢 Варианты источников (каждый с новой строки)
- ✅ Текст после регистрации (поддерживает HTML-разметку)

**Фото:**
- 📅 Программа форума (фото + опциональная подпись)
- 🗣 Спикеры (одно фото со всеми спикерами + подпись)
- 💬 Фото для приветственного сообщения
- 🏢 Фото площадки (показывается в разделе «Информация о форуме»)

**Бонус за регистрацию:**

Кнопка «🎁 Бонус» переключает отправку бонуса:
- **❌ Выкл** (по умолчанию) — бонус не отправляется
- **✅ Вкл** — после регистрации пользователь получает файл

Через кнопку «📎 Бонус за регистрацию» можно загрузить:
- **Документ** (PDF, DOCX и т.д.) — отправляется как файл
- **Фото** с подписью — отправляется как фото

Подпись к файлу сохраняется автоматически. Если бонус включен, но файл не загружен — ничего не отправляется.

**Как редактировать:**
1. Нажмите ✏️ (для текста), 📷 (для фото) или 📎 (для файлов) рядом с нужным полем
2. Отправьте новое значение, фото или документ
3. Фото/документы можно отправить с подписью — она сохранится
4. Чтобы скрыть/удалить значение, отправьте `-`
5. Чтобы отменить — нажмите кнопку «❌ Отмена» или отправьте «Отмена» / `/cancel`

Все изменения применяются **мгновенно** — перезапуск бота не нужен.

### Конструктор регистрации

Через **📋 Вопросы регистрации** в настройках можно включать и выключать любые вопросы полной формы. Доступно 19 вопросов:

| Вопрос | По умолчанию | Описание |
|--------|:---:|----------|
| 🎂 Возраст | ✅ | Числом, 10–120 |
| 📧 Email | ❌ | Валидация формата |
| 📱 Телефон | ❌ | Ввод текстом или кнопка «Поделиться контактом» |
| 🏙 Город | ❌ | Свободный ввод или «Пропустить» |
| 📢 Источник | ✅ | Откуда узнал о форуме (варианты настраиваются) |
| 🏢 Лок. комитет | ❌ | Выбор из списка или свой |
| 👔 Позиция | ❌ | AIESECer / Alumni / AIESEC Friend / свой |
| 🎓 Образование | ✅ | Учится ли сейчас |
| 🏫 ВУЗ | ✅ | Показывается только если учится |
| 📖 Курс | ✅ | Показывается только если учится |
| 📝 Специальность | ✅ | Показывается только если учится |
| 💼 Работа | ✅ | Работает ли сейчас |
| 🏭 Сфера работы | ✅ | Показывается только если работает |
| 💡 Навыки | ✅ | Каких не хватает |
| 💬 Ожидания | ✅ | От форума |
| ✨ Ожидания AR | ❌ | От годового отчёта |
| 📍 Формат | ❌ | Offline / Online |
| 🏕 Неформальный день | ❌ | Пропускается для онлайн-участников |
| 💬 Комментарии | ❌ | Свободный ввод |

Зависимые вопросы пропускаются автоматически:
- ВУЗ / Курс / Специальность — только если ответил «Да» на вопрос об образовании
- Сфера работы — только если ответил «Да» на вопрос о работе
- Неформальный день — пропускается при формате «Online»

Прогресс показывается как `(1/N)` где N — количество включённых шагов.

### Управление меню

Через **🔘 Кнопки меню** в настройках можно показывать и скрывать кнопки главного меню пользователя:

- 🔗 Моя реферальная ссылка
- 👥 Мои приглашённые
- ℹ️ Информация о форуме
- 📅 Программа форума
- 🗣 Спикеры
- 📞 Контакты
- ❓ Задать вопрос

Все кнопки включены по умолчанию. Изменения применяются для новых сообщений — пользователям нужно нажать любую кнопку или отправить `/start`, чтобы обновить меню.

### Синхронизация Google Sheets

Кнопка **🔄 Синхронизация таблицы** в админ-панели сравнивает Telegram ID из первой колонки Google Таблицы с записями в БД и дописывает отсутствующие строки. Полезно если:
- Бот работал без Google Sheets, а потом таблицу подключили
- Были ошибки записи в таблицу
- Таблица была очищена или пересоздана

### Тестирование регистрации

Админы при повторном `/start` видят кнопку «🔄 Пройти регистрацию заново» — позволяет протестировать поток без очистки БД.

### Рассылки

Рассылку можно запустить двумя способами:
- Через кнопку **📢 Рассылка** в админ-панели
- Командой `/broadcast`

**Целевая аудитория:**
- **Все пользователи** — отправка всем зарегистрированным
- **По файлу** — только пользователям из `data/broadcast_target.txt` (по одному Telegram ID на строку)

**Поддерживаемые форматы сообщений:**
- Текст (с HTML-разметкой и ссылками)
- Фото с подписью
- Альбом (несколько фото)
- Видео, документы, аудио

Чтобы отменить рассылку до отправки — нажмите «❌ Отмена» или отправьте «Отмена» / `/cancel`.

### Ответы на вопросы

Когда пользователь задаёт вопрос через кнопку «❓ Задать вопрос», все админы получают уведомление:

```
❓ Новый вопрос от @username:
🆔 123456789

Текст вопроса

↩️ Ответьте reply'ем на это сообщение, чтобы отправить ответ.
```

**Как ответить:** сделайте reply (ответ) на это сообщение в Telegram и напишите текст. Бот перешлёт ответ пользователю с пометкой «💬 Ответ от организаторов». Можно отправить текст, фото или любой другой тип сообщения.

После ответа остальные админы получат уведомление, что вопрос уже обработан.

### Реферальные ссылки с метками

Команда `/create_link <название>` создаёт ссылку с меткой источника:

```
/create_link vk_poster
→ https://t.me/bot_username?start=src_vk_poster
```

Примеры использования:
- `/create_link vk_poster` — для постера ВК
- `/create_link inst_stories` — для сторис в Instagram
- `/create_link ambassador_ivan` — для конкретного амбассадора
- `/create_link university_itmo` — для распространения в ИТМО

Пользователи, перешедшие по такой ссылке, получат соответствующую метку в поле «источник». Статистику по всем меткам смотрите в разделе **📈 Источники** админ-панели.

### Поиск пользователей

```
/find @username
```

Показывает данные зарегистрированного пользователя: ID, имя, email, дату регистрации.

### Кастомные эмодзи (ограничение)

Обычные боты **не могут** отправлять и пересылать кастомные эмодзи (Telegram Premium) в сообщениях. При рассылке (`copyMessage`) они заменяются на обычные.

Чтобы разблокировать поддержку, нужно купить коллектируемый юзернейм для бота на [Fragment](https://fragment.com/). Можно взять любой дешёвый — он привязывается как дополнительный, основной юзернейм бота не меняется.

> Это ограничение Telegram Bot API, а не бота. Без покупки юзернейма на Fragment обойти его невозможно.

## Что видит пользователь

### Регистрация

При первом `/start` пользователь видит приветственное сообщение (с фото, если загружено) и проходит регистрацию. Объём зависит от режима (настраивается админом):

**Краткая форма:** только имя

**Полная форма:** имя → включённые в конструкторе вопросы (по умолчанию: возраст, источник, образование, ВУЗ/курс/специальность, работа/сфера, навыки, ожидания)

На любом шаге можно нажать «Отмена» и начать заново через `/start`.

Если пользователь пришёл по реферальной ссылке другого участника — это фиксируется автоматически.

### Главное меню

После регистрации доступны кнопки (видимость настраивается админом):

| Кнопка | Описание |
|--------|----------|
| 🔗 Моя реферальная ссылка | Личная ссылка для приглашения друзей |
| 👥 Мои приглашённые | Список людей, зарегистрировавшихся по ссылке |
| ℹ️ Информация о форуме | Дата, время, место проведения |
| 📅 Программа форума | Фото с программой |
| 🗣 Спикеры | Фото спикеров |
| 📞 Контакты | Контактное лицо + ссылки на группы |
| ❓ Задать вопрос | Вопрос передаётся напрямую организаторам |

## Архитектура

### Структура проекта

```
AIESEC/
├── main.py                  # Точка входа, настройка бота и роутеров
├── config.py                # Конфигурация через pydantic-settings (.env)
├── requirements.txt         # Зависимости Python
├── google_credentials.json  # Ключ сервисного аккаунта Google (не в git!)
├── .env                     # Переменные окружения (не в git!)
├── .env.example             # Пример .env
├── Dockerfile               # Образ для Docker
├── docker-compose.yml       # Запуск через Docker Compose
│
├── handlers/
│   ├── admin.py             # Админ-панель, настройки, рассылки, статистика, тоглы
│   ├── registration.py      # Движок регистрации (REG_FLOW), /start
│   ├── user_actions.py      # Пользовательские кнопки и действия
│   └── states.py            # FSM-состояния (Registration, Question, Broadcast, EditSetting)
│
├── keyboards/
│   └── builders.py          # Все клавиатуры (reply и inline), динамическое меню
│
├── database/
│   └── db.py                # Работа с SQLite (aiosqlite)
│
├── services/
│   └── sheets.py            # Интеграция с Google Sheets (gspread) + retry
│
├── resources/               # Необязательные fallback-фото (загружайте через админку)
│   ├── start.jpg            # Фото для /start (опционально)
│   ├── venue.jpg            # Фото площадки (опционально)
│   └── program.jpg          # Фото программы (опционально)
│
└── data/                    # Рантайм-данные (создаются автоматически)
    ├── forum.db             # SQLite база
    └── broadcast_target.txt # Список ID для таргетированной рассылки
```

### Стек

| Компонент | Технология |
|-----------|------------|
| Фреймворк | [aiogram 3](https://docs.aiogram.dev/) (async) |
| БД | SQLite через [aiosqlite](https://github.com/omnilib/aiosqlite) |
| Конфигурация | [pydantic-settings](https://docs.pydantic.dev/latest/concepts/pydantic_settings/) + `.env` |
| Google Sheets | [gspread](https://docs.gspread.org/) + сервисный аккаунт |
| Режим работы | Long polling (не webhooks) |

**Таблица `users`** — все зарегистрированные пользователи:

| Поле | Тип | Описание |
|------|-----|----------|
| telegram_id | INTEGER PK | Telegram ID |
| username | TEXT | @username |
| full_name | TEXT | Имя и фамилия |

### Порядок обработки сообщений

Роутеры подключаются в `main.py` в определённом порядке:

1. **admin** — перехватывает команды админов и reply-ответы на вопросы
2. **registration** — обрабатывает `/start` и поток регистрации
3. **user_actions** — кнопки главного меню и вопросы пользователей

Порядок важен: aiogram 3 проверяет хендлеры сверху вниз и останавливается на первом совпавшем.

### FSM (конечные автоматы)

Бот использует Finite State Machine для многошаговых взаимодействий:

| Группа | Состояния | Кто использует |
|--------|-----------|----------------|
| Registration | admin_rereg → full_name → (динамический поток из включённых вопросов) | Пользователь при регистрации; админ при тестовой перерегистрации |
| Question | waiting_for_question | Пользователь при отправке вопроса |
| Broadcast | target_selection → message | Админ при рассылке |
| EditSetting | waiting_for_value, waiting_for_photo, waiting_for_file | Админ при редактировании настроек |

Динамический поток регистрации управляется движком `REG_FLOW` — последовательность шагов определяется на лету по включённым настройкам и ответам пользователя. Зависимые шаги (ВУЗ, сфера работы) пропускаются автоматически.

Во всех состояниях доступна отмена через кнопку «Отмена», команду `/cancel` или inline-кнопку «❌ Отмена».

FSM-хранилище — `MemoryStorage` (в оперативной памяти). При перезапуске бота все незавершённые состояния сбрасываются.
