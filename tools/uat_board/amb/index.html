Правила мест

Чтобы пакетов хватило на всех

1
Место в 17 занимает только амбассадор с одобренной заявкой на форум. Без неё он в команде, но «без пакета» и в лимит не входит.
2
Отдала подарок — отметь «🎁 Пакет выдан». Если такой человек потом уйдёт, его место не освободится.
3
Ушёл без подарка — жми «🚪 Вывести из команды». Бот заранее пишет, освободится ли место и какое сообщение получит человек.
4
Освободилось место — вопрос в анкете и кнопка снова появляются, а ты берёшь следующего из запаса.
5
Люди, приглашённые до отбора, засчитываются по ссылке. Кто пришёл без ссылки — закрепление вручную появится в следующих шагах.
Проверено

Прогнали на тестовом боте с настройками РилТолка

  • ✓ «Да» в анкете → кандидат, подтверждение и личная ссылка приходят сразу
  • ✓ Одобрение заявки на форум не делает амбассадором само — решаешь ты
  • ✓ «Взять» → человеку приходит «Ты в команде!», счётчик «1 из 1»
  • ✓ Места заняты → вопрос «Хочешь стать амбассадором?» пропадает из анкеты
  • ✓ Лимит меняется числом, на «abc» бот объясняет, что прислать
  • ✓ «Пакет выдан» + «Вывести из команды» → место остаётся за человеком
  • ✓ Кнопка «Хочу свою ссылку» в режиме отбора → «заявка рассматривается»
  • ✓ «Вежливо отказать всем» → подтверждение со счётом, рассылка, отчёт
  • ✓ Около 8 270 автотестов бота — зелёные

Права

Выдать тебе право «🎮 Модерация геймификации» (раздел и кнопки) и «⚙️ Настройки» — для правки текстов.

Анкета

Вопрос «Дата рождения» ждёт возраст числом — переименовать в «Сколько тебе лет?». Убрать вариант «Соцсети Юлид» из «Откуда узнал(а)».

Сезон

Задать название сезона, чтобы работали архив прошлых составов и сброс на новый сезон.

Выкат

Обновление бота РилТолка с резервной копией базы — в тихое время, по команде.
